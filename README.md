> **Mission**: Turning Education into Action for Viksit Bharat @2047

---

## 🌟 Overview

**YuvaSetu AI** is a full-stack AI-powered educational and skilling platform designed to empower learners across India by addressing three fundamental challenges:

1. **Identifying Learning & Skill Gaps**: Instant diagnostic evaluation tailored to high school (Class 8–12), college degrees, ITI trades, polytechnics, job seekers, and working professionals.
2. **Personalized Paced Guidance & Vernacular Support**: Dynamic 7-day & 30-day study plans adapting to learner pace, with full Hindi and English career roadmaps.
3. **Linkage to Government Skilling Pathways**: Connecting learner upskilling directly to verified official government portals (**Skill India Digital**, **National Career Service (NCS)**, **FutureSkills Prime**, **NSQF Framework**, **UDISE+**, and **AISHE**).

---

## 🔥 Key Highlights & Features

- **India Education & Skill Explorer**: Comprehensive dashboard table spanning all **28 States + 8 Union Territories (36 Total)** with category filters, real-time search, education context, key skill areas, regional languages, and official government references.
- **AI Skill Diagnostic Engine**: Real-time readiness scoring (0–100%) and learning gap identification for target career goals.
- **Dynamic 7-Day & 30-Day Study Plan**: Interactive task checklist with customizable daily available time and difficulty levels.
- **Regional-Language Career Guide**: Native Hindi and English step-by-step career guidance roadmaps.
- **YuvaGov Bridge**: Strategic linkage matching learner skill profiles to official government pathways.
- **8 Dynamic Visualizations**: Logically grouped Chart.js visualizations (*My Skill Profile*, *My Learning Journey*, *My Career Readiness*, *My Next Steps & Impact*).
- **Viksit Bharat 2047 Impact Page**: Strategic roadmap (`NOW → 2047`), 8-stage transition visual, BEFORE vs AFTER comparative flows, and project impact model.

## 🚀 Quick Start Guide

### Prerequisites
- [Node.js](https://nodejs.org/) (v16+ recommended)
- [Git](https://git-scm.com/)

### 1. Clone the Repository
```bash
git clone https://github.com/YOUR_USERNAME/yuvasetu-ai.git
cd yuvasetu-ai
```

### 2. Install Dependencies & Start Dev Server
```bash
npm install
npm run dev
```
Open `http://localhost:3000/` in your browser.

### 3. Production Build
```bash
npm run build
```
